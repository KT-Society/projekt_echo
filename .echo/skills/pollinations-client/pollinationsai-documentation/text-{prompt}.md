# Endpoint: /text/{prompt}\n\n## Method: GET\n\n**Summary:** Simple Text Generation\n\n**Description:** Generate text from a prompt via a simple GET request. Returns plain text.

This is a simplified alternative to the OpenAI-compatible `/v1/chat/completions` endpoint — ideal for quick prototyping or simple integrations.\n\n### Parameters\n\n- **prompt** (path): Text prompt for generation\n- **model** (query): Text model to use. See /v1/models or /text/models for the full list of available models.\n- **seed** (query): Seed for reproducible results. -1 maps to the stable compatibility seed.\n- **system** (query): System prompt to set the model's behavior and context. Acts as initial instructions before the user prompt.\n- **json** (query): When true, the model returns valid JSON. Useful for structured data extraction.\n- **temperature** (query): Controls randomness. Lower values (e.g. 0.2) produce more focused output, higher values (e.g. 1.5) produce more creative output. Range: 0.0 to 2.0.\n- **top_p** (query): N/A\n- **presence_penalty** (query): N/A\n- **frequency_penalty** (query): N/A\n- **repetition_penalty** (query): N/A\n- **max_tokens** (query): N/A\n- **max_completion_tokens** (query): N/A\n- **reasoning_effort** (query): N/A\n- **voice** (query): N/A\n- **stream** (query): Stream the response as it's generated, using Server-Sent Events (SSE). Each chunk contains partial text.\n- **safe** (query): Safety features: comma-separated list of privacy, secrets, sexual, violence, shield, true, nsfw. true enables privacy,secrets; nsfw enables sexual,violence. Also accepted in the Pollinations-Safe header. Defaults to off; false and 0 are accepted as off.\n\n
