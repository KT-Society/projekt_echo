# Endpoint: /account/earnings\n\n## Method: GET\n\n**Summary:** Get Developer Earnings\n\n**Description:** Returns developer earnings in one response: per-(date, entity) buckets and per-entity rollups across BYOP apps and community models. Rows include `requests`, `baseline_price`, reward basis `cost_usd`, and `reward_rate`. Use `days` for rolling windows or `granularity` and `period` for exact day/week/month periods. API keys require the read-only `account:usage` permission.\n\n### Parameters\n\n- **format** (query): N/A\n- **days** (query): N/A\n- **granularity** (query): N/A\n- **period** (query): N/A\n\n
