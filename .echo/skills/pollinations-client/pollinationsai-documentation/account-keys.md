# Endpoint: /account/keys\n\n## Method: GET\n\n**Summary:** List API Keys\n\n**Description:** List all API keys for the current user. Requires `account:keys` permission when using API keys. Secret key values are never returned.\n\n## Method: POST\n\n**Summary:** Create API Key\n\n**Description:** Create a new API key. To create an app key, use `type: "publishable"` with `redirectUris`. Publishable app keys default developer earnings off; send `earningsEnabled: true` to opt in. Requires `account:keys` permission when using API keys. The full key value is returned only once in the response. The `keys` account permission is automatically stripped from child keys to prevent escalation.\n\n
