# Endpoint: /account/usage/daily\n\n## Method: GET\n\n**Summary:** Get Daily Usage\n\n**Description:** Returns aggregated usage for the requested time window, grouped by date, API key, model, and billing source. Use `days` for rolling windows or `granularity` and `period` for exact day/week/month periods. Useful for dashboards and spending analysis. Supports JSON and CSV export. Requires `account:usage` permission when using API keys.\n\n### Parameters\n\n- **format** (query): N/A\n- **days** (query): N/A\n- **granularity** (query): N/A\n- **period** (query): N/A\n- **api_key_ids** (query): N/A\n\n
