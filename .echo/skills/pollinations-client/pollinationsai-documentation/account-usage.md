# Endpoint: /account/usage\n\n## Method: GET\n\n**Summary:** Get Usage History\n\n**Description:** Returns your request history with per-request details: model used, token counts, cost, and response time. Defaults to the last 30 days, supports up to 90 days via `days`, or exact day/week/month periods via `granularity` and `period`. Supports JSON and CSV export. Each response is capped at 50,000 rows. Use `before` with `before_event_id` for stable cursor-based pagination. API keys require the read-only `account:usage` permission.\n\n### Parameters\n\n- **format** (query): N/A\n- **limit** (query): N/A\n- **before** (query): N/A\n- **before_event_id** (query): N/A\n- **days** (query): N/A\n- **granularity** (query): N/A\n- **period** (query): N/A\n- **api_key_ids** (query): N/A\n- **models** (query): N/A\n\n
