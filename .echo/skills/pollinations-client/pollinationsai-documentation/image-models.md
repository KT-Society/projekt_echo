# Endpoint: /image/models\n\n## Method: GET\n\n**Summary:** List Image & Video Models\n\n**Description:** Returns all available image and video generation models with pricing, capabilities, and metadata. Video models are included here — check the `outputModalities` field to distinguish image vs video models. When authenticated: models are filtered by API key permissions, and `paid_only` models are hidden if the account has no paid balance. Pass `?community=false` to exclude community models or `?community=true` to return only community models.\n\n### Parameters\n\n- **community** (query): Filter by community status: `true`/`1` for community-only, `false`/`0` for official-only. Omit for all models.\n\n
