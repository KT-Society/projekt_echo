# Endpoint: /account/key/usage\n\n## Method: GET\n\n**Summary:** Get API Key Usage\n\n**Description:** Returns usage history for the API key used in the request. No scope required — a key can always read its own usage. Use `before` with `before_event_id` for stable cursor-based pagination. For account-wide usage across all keys, use `/account/usage` with `account:usage`.\n\n### Parameters\n\n- **format** (query): N/A\n- **limit** (query): N/A\n- **before** (query): N/A\n- **before_event_id** (query): N/A\n- **days** (query): N/A\n- **granularity** (query): N/A\n- **period** (query): N/A\n- **api_key_ids** (query): N/A\n- **models** (query): N/A\n\n
